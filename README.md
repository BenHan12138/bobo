# Bobo Demo App

A simple Java console application that greets users.

## Prerequisites

- JDK 17+
- Maven 3.8+

## Build

```bash
mvn clean package
```

## Run

```bash
java -jar target/bobo-app-1.0-SNAPSHOT.jar Alice 25
```

Output:
```
Hello, Alice. Welcome aboard!
Goodbye, Alice. See you soon!
```

## Test

```bash
mvn test
```
